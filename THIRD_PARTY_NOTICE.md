## Object-location photographs

The application currently configures 24 JPEG photographs under `assets/images/objects/`; these are active stimuli, not merely unused example placeholders. Their per-file inventory is `assets/images/objects/provenance_ledger.csv`.

Each ledger entry records an immutable Git blob identifier, but the creator, original source, applicable licence, and permission to reproduce or redistribute each photograph are currently unknown. A Git identifier establishes file identity only; it supplies no ownership or permission evidence.

Their inclusion in a public repository or archived research snapshot does not constitute a licence grant or resolve third-party copyright. Until every file is cleared, removed, or replaced with appropriately licensed stimuli, the object-photo collection must be treated as an unresolved rights gate. Visual, cultural, and stimulus-format validation remains separately necessary.
