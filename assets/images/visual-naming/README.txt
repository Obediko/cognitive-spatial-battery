VISUAL NAMING PHOTO STIMULI — 32 ITEMS

Contents
--------
32 standardized 1024 × 1024 PNG files.
All stimuli are real-object photographs; no custom line drawings are used.
A source_manifest.csv records the source for every stimulus.

Source strategy
---------------
• BOSS (Bank of Standardized Stimuli) was used wherever a clear matching object was available.
• Wikimedia Commons photographs were used for objects not adequately represented in BOSS.
• Images were visually screened for object recognizability and obvious ambiguity.

Important psychometric note
---------------------------
This is a custom stimulus set, NOT an official NAB, Boston Naming Test, MINT, or other proprietary test.
Replacing the official images of a standardized cognitive battery changes its psychometric properties.
Before using scores inferentially, pilot naming agreement/familiarity in the population you intend to study.

Recommended pilot QC
--------------------
Record spontaneous naming, accepted synonyms, naming latency, familiarity, and visual clarity.
Items such as sextant, astrolabe, yoke, bellows, plumb bob, trellis and periscope are inherently
lower-frequency concepts, so errors may partly reflect object familiarity rather than lexical retrieval.

Licensing
