## Image standard

- Use one consistent stimulus type across all 32 items: either isolated photographs or professionally produced line art. Do not mix the two.
- Square PNG, preferably 1024 × 1024 px or larger.
- One object only, centred, fully visible, with consistent apparent size and viewing angle.
- Plain white or transparent background; no scene context, text, people, hands, brands, shadows that reveal use, or decorative borders.
- Verify that the depicted object is culturally recognizable and visually unambiguous.
- Use only project-created, commissioned, public-domain, or explicitly licensed material.
- Complete `manifest.json` with creator/source URL, licence, and permission notes for every file.

Changing from SVG line drawings to photographs changes the task and requires new name-agreement and difficulty validation. Preserve the full image set under a new stimulus-set version when it is frozen.
